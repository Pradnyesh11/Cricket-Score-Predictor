# 🏏 Cricket Score Predictor

A Machine Learning project to predict the final score of a cricket match based on ball-by-ball match state.

## 📂 Project Structure

```
Cricket Score Predictor/
│
├── data/
│   ├── yaml_matches/       ← Put ALL Cricsheet .yaml files here
│   ├── t20_balls.csv       ← Generated by 01_data_loading.py
│   ├── odi_balls.csv
│   └── test_balls.csv
│
├── notebooks/
│   ├── 01_data_loading.py      ← Step 1: Load YAML → CSV
│   ├── 02_eda.py               ← Step 2: Exploratory Data Analysis
│   ├── 03_feature_engineering.py ← Step 3: Build ML features
│   └── 04_model_training.py    ← Step 4: Train & evaluate models
│
├── models/
│   ├── cricket_score_model.joblib  ← Saved trained model
│   └── scaler.joblib               ← Saved feature scaler
│
├── app/                        ← Web app (built after model training)
│
└── README.md
```

## ⚡ Getting Started

### 1. Install dependencies
```bash
pip install pyyaml pandas numpy scikit-learn xgboost tqdm matplotlib seaborn joblib
```

### 2. Add your dataset
Place all your Cricsheet `.yaml` files inside `data/yaml_matches/`

### 3. Run scripts in order
```bash
python notebooks/01_data_loading.py
python notebooks/02_eda.py
python notebooks/03_feature_engineering.py
python notebooks/04_model_training.py
```

## 🧠 Model Info
- **Algorithm**: XGBoost Regressor (with Random Forest as baseline)
- **Target**: Predicted final score of the batting team
- **Key Features**: Cumulative runs, wickets fallen, overs completed, run rate, venue, teams

## Run the prediction interface

The Streamlit interface uses `t20_score_predictor.pkl`. Double-click
`app\run_app.bat`, or install and run it from the project root:

```powershell
python -m pip install -r app\requirements.txt
python -m streamlit run app\app.py
```

The interface accepts live innings inputs and updates the estimate as they change.
Team names are shown instead of encoded IDs. The original city mapping was not saved,
so the predictor uses its most common trained city code.
